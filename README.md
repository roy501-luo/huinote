# 会议助手 · macOS

面向 Apple Silicon 的原生中文 AI 会议助手。SwiftUI 界面、本地会议资料库、双路录音，接入阿里云百炼实时转写和会后处理。无需自建后端、账号系统或向量数据库。

## 功能

- **录音与转写**：系统音频和麦克风独立采集、保存和实时转写，显示临时结果、最终结果、连接状态与缺失提示。
- **会后说话人稿**：单声道混音通过百炼临时 OSS 提交 Fun-ASR，生成句子级时间点和说话人编号；保留实时原稿。
- **听读核对**：播放时高亮当前句子并跟随，手动滚动暂停跟随，一键恢复；支持变速和定位。
- **笔记与纪要**：可编辑笔记，模板选择、新建、复制、修改及自定义模板删除。生成总结、决策、行动项与未解决问题，并自动更新会议名称。
- **后台批量生成**：统一选择模板，会议级断点恢复、失败项重试；生成期间可浏览会议和新建会议。
- **会议库**：SQLite FTS5 全文搜索、关键词高亮、多选删除、Markdown 导出。
- **本场问答**：可收起的右侧问答面板，依据原文和笔记作答，点击引用返回原文；资料不足时提示无依据。
- **Plaud 接入（可选）**：导入既有资料并按文件 ID 去重；下载录音后使用会议助手的识别与纪要流程。下载依赖外部本地采集工具，见 [配置说明](docs/CONFIGURATION.md)。

说话人编号不代表真实身份。当前不包含跨会议自动声纹认人、跨会议语义问答或云同步。

## 快速开始

要求 Apple Silicon、macOS 14+、Swift 6 工具链和 macOS SDK。开发验证环境为 macOS 26.2、Swift 6.3.1；其他系统版本尚未逐一验收。

```sh
xcode-select --install # 已安装 Command Line Tools 时跳过
```

1. 克隆项目并进入目录。
2. 按 [签名说明](signing/README.md) 创建自己的固定代码签名身份，将证书 SHA-1 指纹保存到 `signing/identity.txt`（不提交 Git）。
3. 构建并启动：

```sh
./scripts/build.sh
open dist/会议助手.app
```

4. 在 App 设置中填入北京地域的 ASR、LLM Key，并保存到钥匙串；不要放入源码或环境文件。
5. 开始会议，根据系统提示授权麦克风和屏幕／系统音频录制。推荐佩戴耳机，外放会导致重复收音。

更新时先结束录音并退出旧版本，始终使用同一签名身份、Bundle ID 和安装路径。不要删除钥匙串组件缓存；固定签名与组件复用用于减少重复授权。自行编译的 App 未经 Apple 公证，不是通用签名安装包。

## 数据与网络

会议数据库、录音、笔记、转写和纪要保存在 `~/Library/Application Support/MeetingAssistant/`；API Key 保存在 macOS 钥匙串。

这不是离线识别软件：实时录音发送至配置的 ASR 服务；会后录音上传至百炼临时存储；转写和笔记发送至配置的 LLM 服务。自动会后处理可在设置关闭，API 调用按服务商计费。完整数据流见 [配置与隐私](docs/CONFIGURATION.md)。

本仓库不包含个人录音、会议文本、数据库、API Key、签名私钥、运行日志或预编译签名组件。
