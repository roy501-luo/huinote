# 录音期间的自动熄屏防护

2026-10-16：录音成功启动后申请 ProcessInfo activity，阻止空闲系统休眠与自动熄屏。暂停/结束立即释放，继续重新申请；对象销毁也释放。不修改系统电源偏好，不影响非录音时的自动熄屏。

Verification/VerifyRecordingActivity.swift 在真实 macOS 上通过 pmset 检查本进程的系统/显示休眠断言：空闲无断言、启动后两类断言存在、重复更新不累加、暂停释放、继续恢复、结束释放、析构释放均通过。Release 构建和签名通过。这是电源机制实测，尚非跨越用户自动熄屏时限的长录音验收。

手动锁屏、合盖或强制休眠不在空闲休眠断言保证范围内；未采集音频不能凭转写恢复。Apple API：https://developer.apple.com/documentation/foundation/processinfo/activityoptions/idledisplaysleepdisabled

## 异常收尾修复

停止系统采集改为有期限的回调等待（5秒），先移除输出，再等待已有队列并关闭本地文件。回调缺失时保留错误提示，防止无限“正在收尾”；重复或迟到回调只完成一次。时长在等待采集停止前保存。验证器覆盖缺失回调、成功回调、重复回调与超时后不重复完成；完整核心回归通过。

本机异常记录恢复前已备份数据库及原录音；按录音采样数和分段偏移恢复实际时长，保留原转写及音源缺失标记。原文件全量解码、实际播放验证通过。没有把计时器运行时间当成实际采集时长，也没有声称能补回中断后的声音。重复启动实测第二进程退出，只保留 Applications 实例。超过自动熄屏时限的真实录音验证仍待用户方便时进行。
