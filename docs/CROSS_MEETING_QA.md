# 跨会议问答

入口：主窗口左侧“跨会议问答”。支持全部会议、指定会议和文件夹范围；每次问题独立回答，历史回答保留当次范围快照，可再次提问。

只使用选定范围的转写与用户文字笔记，不使用生成的总结或历史回答作证据。有说话人稿时优先使用说话人稿，避免与实时稿重复。无原文的会议计数显示在回答下；长资料分段读取，不静默截断。全部资料范围较大时，响应时间与模型用量随原文增长。

引用包含会议、发言人、时间点。每条引用校验实际原文与范围，点击后切换会议并定位原句。会议删除、原文或发言人元数据变动后提示重新提问。用户笔记引用沿用笔记原文快照查看方式。不同会议同编号说话人不推断为同一人。

问答记录保存为资料目录中的 `library-questions.json`；不改写原会议总结、转写或检索词。处理可以取消，重启后未完成记录标为中断并可再次提问。
