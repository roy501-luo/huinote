# HuiNote · 会记 v0.1

第一版来了。把录音、转写、笔记、总结和问答，放进一个原生 macOS App。

## 这一版能做什么

- 双路录音与实时中文转写，会后生成带时间点的说话人稿。
- 播放时高亮、跟随当前句子，方便边听边核对。
- 选择或自建模板生成纪要，支持批量总结、断点恢复与自动命名。
- 搜索历史会议，或直接提问，点击引用返回原文。
- 导入 Plaud 资料，导出 Markdown。

## 开始使用

1. 下载下方 **HuiNote-v0.1-arm64.zip**，解压后将 App 放入「应用程序」。
2. 在设置中填写自己的百炼北京地域 ASR 和 LLM Key。
3. 授权录音，开始会议。

适用于 **Apple Silicon、macOS 14+**。首次打开与 Key 配置见 [安装指南](https://github.com/roy501-luo/huinote/blob/main/docs/INSTALL.md)。

欢迎到 [Issues](https://github.com/roy501-luo/huinote/issues) 反馈使用感受和问题。
