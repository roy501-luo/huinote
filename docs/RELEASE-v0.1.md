# HuiNote · 会记 v0.1

首个公开下载的 macOS Apple Silicon 测试包。下载 ZIP 后将 App 放入「应用程序」，在设置中填写自己的百炼北京地域 ASR 与 LLM Key。

## 包含功能

双路本地录音、实时中文转写、会后说话人分离、笔记与模板纪要、自动标题、全文搜索高亮、带引用的本场问答、播放跟随、批量总结与会议级断点恢复。Plaud 为可选外部工具接入。

## 安装

下载 **MeetingAssistant-v0.1-arm64.zip**；安装说明见 **INSTALL.md**，完整性校验见 **SHA256SUMS.txt**。要求 Apple Silicon、macOS 14+，开发验证环境为 macOS 26.2。

**自签名、未公证**：首次打开可能被 macOS 拦截。确认来源后通过「隐私与安全性 → 仍要打开」手动放行；如设备策略禁止，联系维护者，不要关闭系统安全保护。无需安装证书或开发工具。

API Key 由使用者自己提供并保存在自己的钥匙串。包内不含个人会议或密钥；服务调用会产生费用，音频及原文会按功能发送到百炼／配置的 LLM。

## 验证与限制

核心验证通过，采用 release 优化构建并检查签名及解包完整性。既有开发机真实录音和 API 分项验证不等于新设备首装验收：另一台干净 Mac 上的 Gatekeeper 放行、钥匙串首次保存及录音权限全流程尚未验证。

实时断线不自动回填；会后文件识别限制两小时以内；批量恢复粒度为整场会议；后台总结同时录音的完整回归仍需补齐。说话人聚类与模型纪要需要人工核对。不包含跨会议声纹认人和跨会议问答。

这是预发布测试版，不是稳定版。仓库及 Release 公开，任何人均可下载。
