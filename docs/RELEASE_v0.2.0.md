# HuiNote · 会记 v0.2.0

本次更新集中完善会议工作空间与日常使用体验。

- 文件夹、主区域会议列表、全局搜索与独立模板管理；返回详情保留阅读状态。
- 跨会议问答支持全部、文件夹或指定会议，严格核对引用，跳转原文后可返回。
- 统一生成入口：选择模板、核对发言人，已有转写复用；失败保留原有总结并支持重试。
- 发言人颜色与独立维护侧栏、总结原文并排核对、播放跟随和自动检索词。
- 会中标记支持文字、自动时间戳和图片；改善中文输入与频繁保存造成的卡顿。
- 弱网本地录音、恢复实时转写、会后补齐；批量任务断点恢复及失败重试。
- 修复录音状态栏遮挡，结束会议直接进入详情；后台读取钥匙串配置，减少启动时界面阻塞。
- 优化空闲定时任务与发布构建。短时空闲采样 CPU 为0.0%，详见性能记录，非续航承诺。

支持 Apple Silicon、macOS 14+。自备百炼 Key；安装与首次打开方式见包内 INSTALL.md。既有资料库及钥匙串兼容。本测试版尚未 Apple 公证。

验证：核心回归、中文组合输入、Plaud 登录恢复模拟、优化构建、签名与安装包校验通过。短静音录音的云端会后识别仍可能失败；保留录音与已有总结供重试。真实设备和 API 的分阶段验证记录见 docs，未将自动测试视为全设备端到端验收。
