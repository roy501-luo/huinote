- 搜索逐字删除、一键清空与关闭后，原会议保持；总结标签搜索返回转写后，暂停位置仍为 12.60 秒，本场查找词保留。
- 当前句蓝色加粗与查找词黄色背景同时显示；单击正文定位到 40.48 秒，继续播放至后续句子时高亮随之迁移。验证结束已停止播放。
- 正式资料库全部会议记录与测试前逐字节一致；临时副本总结、转写和标签恢复至原值。测试库不纳入 Git。
- 完整 `scripts/verify.sh` 通过，包括历史关键词清理幂等、手工词保留、总结不变、搜索索引更新、音频与严格引用校验、原生笔记输入及电源断言释放。

历史自动检索词整理只过滤现有自动词并更新索引，先备份会议记录，不重新生成总结；手动修改标记及手工词保留。规则是保守筛选，不保证自动实体分类全部正确。

防熄屏机制的系统断言检查通过，但超过用户自动熄屏时限的长录音仍待验证，不能将本轮界面回归当成该项验收。详见 [录音与休眠](RECORDING_SLEEP.md) 和 [静音处理边界](SILENT_AUDIO.md)。

## 自动验证

`./scripts/verify.sh` 编译项目真实核心代码并运行隔离测试，不依赖真实 API Key。覆盖：

- SQLite 保存、更新、重开、全文搜索、删除及索引一致性。
- 实时 ASR 临时结果替换、最终结果去重、异常事件与缺失状态。
- 音频重采样、PCM16 限幅、尾帧、有界队列、双路 CAF 写入解码。
- 混音偏移、文件识别结果解析、长文本分段、纪要引用与字段校验。
- Plaud 去重和编辑保留、问答引用与资料版本边界。
- 播放时间区间、重叠句、跟随恢复锚点。
- 批量任务持久化、重复提交保护、失败重试队列。

合成音频测试不代表真实麦克风、系统权限或云端识别成功。私人真实录音及验收输出已从仓库排除。

## 人工回归步骤

1. 保存设置，在本机系统弹窗授权钥匙串和录音；检查状态，不以开关开启推断采集成功。
2. 佩戴耳机，播放中文系统声音，同时说话一分钟。检查双路活动、本地可播放录音与真实实时转写。
3. 停止后等待尾部结果，检查无重复句和缺失提示；观察闲置 CPU。
4. 会后完成说话人分离，人工核对时间点和编号，再核对决策、负责人、期限是否有原文依据。
5. 选择模板生成或重生成纪要，验证标题更新、编辑、导出；失败后旧内容应保留。
6. 搜索标题、短中文、正文和日期，检查关键词高亮；问答引用应跳回原句，无依据问题应提示资料不足。
7. 播放中滚动：音频继续、自动跟随暂停；点击恢复应回到当前句。
8. 批量处理途中浏览、新建会议、暂停与重启；恢复不能重复提交已完成会议；失败项可重试。
9. 单独验证“后台总结同时录制新会议”及结束后的排队流程，防止结果写到错误会议。

## v0.2.0 验证边界（2026-10-15）

本版本自动回归覆盖弱网重连、有界队列、跨会议范围隔离、严格引用校验、原生中文组合输入及本地存储。性能审计见 [性能记录](PERFORMANCE.md)。麦克风、生成重试和导航的阶段性真机结果见本目录对应验证文档；它们不是每次发布都重跑的完整端到端结果。

当前支持断网本地录音、恢复后实时转写、会后自动补齐及跨会议问答。未采集到的声音无法补回；小时级连续录音、蓝牙频繁热切换和 macOS 14 回退分支仍需更多设备验证。短静音录音曾遇到云端会后识别任务失败；失败会保留录音和已有总结，允许重试。模型输出及说话人聚类需要核对，不提供跨会议声纹认人。
