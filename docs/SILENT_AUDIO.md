# 单实例与静音录音处理

启动时在打开资料库前检查相同 Bundle ID 的运行进程，激活已有窗口并退出第二个实例；文件锁覆盖同时启动竞争。不会自动结束正在录音的已有实例。

无最终转写且需要重新识别时，在本地混音转换期间检查每一路 PCM16 音轨。所有样本幅度都不超过 2（接近数字零值）时，标记“无有效音频 · 已跳过生成”，不上传 ASR、不生成总结，并取消自动补齐重试。保留录音和旧总结。任一路存在有效信号即正常处理，静音间隙不裁剪，引用时间轴保持不变。

这是保守静音过滤，不是人声检测；有背景噪声但无发言的录音仍可能提交识别。已有转写生成总结不受此过滤影响。测试覆盖全零、数字零附近噪声、低幅信号和 Int16 极值。
